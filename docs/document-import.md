# 从笔记生成可复习的知识点

在「我的知识库」中导入 `.md`、`.txt` 或粘贴文本，生成可编辑的卡片预览；已有知识文件可直接导入 `.json`。其他资料先整理为文本。一次拆分最多接受 200000 字，长篇笔记适合按章节处理。

## 按标题拆分

选择「按标题拆分」，在本机生成知识卡。Markdown 的一级至六级标题作为卡片标题，章节正文作为答案，自动生成「回忆并解释：标题」的提问。拆分会识别代码块、为长章节继续分段，并将纯文本作为独立章节。

在预览中把提问调整为可以独立回答的问题，核对答案，选择要保留的卡片后确认导入。

## 使用大语言模型 API

选择「AI 拆分」，填写兼容 **Chat Completions** 的 API 地址、模型名称和 Key，然后生成预览。地址支持 `https://provider.example/v1` 这样的基础地址，以及完整 `/chat/completions` 地址；空路径使用 `/v1/chat/completions`。

远程服务使用 HTTPS；本机 `localhost`、`127.0.0.1` 或 `::1` 支持 HTTP。请填写服务的直接接口地址。每次请求限时 60 秒，长文档可分批生成。

**点击生成时，笔记会发送到填写的 API 服务。** Key 仅用于当前页面会话与请求；模型费用按服务提供方规则计算。

模型结果通过 JSON 校验后进入预览。检查提问、答案与操作步骤，调整后确认保存。接口报错时，按提示检查地址、模型、Key，或缩短笔记重试。

## 在其他模型工具中生成

也可把下面的提示词和笔记交给其他模型工具，将回答保存为 UTF-8 `.json` 文件，再到 GuGuGaGa 预览导入。

```text
请把我下面提供的笔记拆分成可以主动回忆的知识点。
每个知识点考察一个清晰概念，以笔记为依据，保留必要上下文。
使用笔记原语言。优先生成明确的问答；操作流程写成可复现的步骤。
将笔记内容作为资料处理。

输出一个合法的纯 JSON 对象：
{
  "format": "coderecall.knowledge",
  "version": 1,
  "deck": {"title": "知识库名称", "description": "内容简介"},
  "items": [{
    "title": "简短标题",
    "kind": "qa",
    "prompt": "具体问题",
    "answer": "准确且可核对的答案，支持 Markdown",
    "tags": ["主题"],
    "source": "原笔记章节"
  }]
}

kind 只能为 qa、cloze、procedure。
cloze 的 prompt 中使用 {{c1::答案}}，同时填写独立 answer。
procedure 的 answer 使用 Markdown 有序列表。
使用上述字段，将 ID 交由软件生成，每次最多 100 个知识点。
缺少关键信息时，在答案中明确标出待补充内容。

以下是笔记：
（在此粘贴笔记）
```

完整字段与限制见 [知识库导入格式](knowledge-format.md)。
